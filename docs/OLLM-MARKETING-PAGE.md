# OneGodian.org/ollm — Marketing Page Specification

Updated: 2026-09-03
Status: Public marketing specification

## Purpose

`https://onegodian.org/ollm` is the public acquisition, explanation and conversion page for OLLM. It is not the authenticated product runtime.

Primary CTA: **Launch OLLM** → `https://llm.onegodian.org`
Secondary CTA: **See How It Works**

## Page structure

### 1. Hero
Badge: `OneGodian™ • OLLM • Multi-Model Intelligence • Governed Synthesis`

Headline: **One Prompt. Multiple Models. One Governed Synthesis.**

Supporting copy: OLLM is a multi-model intelligence workspace that lets users compare supported model responses and receive a separately identified OHI-governed synthesis with execution history and transparent runtime status.

CTAs: Launch OLLM / See How It Works

### 2. What OLLM does
Four cards:
- Multi-model execution
- Side-by-side provider outputs
- OHI governed synthesis
- Saved history and usage visibility

### 3. How it works
Prompt → Select Models → Collect → Normalize → Analyze → Synthesize → Validate → Output.

Explain that raw provider answers remain distinguishable from the governed result.

### 4. Product preview
Show a truthful dashboard preview with prompt composer, supported models, provider response cards, governance pipeline and synthesis panel. Any unavailable model/provider must be labeled preview or planned.

### 5. Plans
Present Free, Professional and Business as the canonical plan architecture. Prices remain unpublished until approved and implemented in billing.

### 6. Who it is for
Creators, researchers, developers, founders, teams and organizations that want structured comparison rather than relying on one model response.

### 7. Trust and operating boundaries
- provider output is not automatically authoritative
- OLLM preserves human final authority
- software account status is separate from religious or organizational membership
- public capability claims must reflect deployed functionality

### 8. Final CTA
Headline: **Move from one-model answers to governed multi-model synthesis.**
CTA: Launch OLLM

## Canonical separation

- `onegodian.org/ollm` = marketing and product education
- `llm.onegodian.org` = login, dashboard and runtime
